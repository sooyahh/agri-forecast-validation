# 방법론 상세: 옥수수·대두 가격예측과 연도별 검증

먼저 [실험 보고서](single_split_report.ko.md)를 읽고 [모델 비교표](../results/model_metrics.csv)와 [거래 비교표](../results/strategy_metrics.csv)에서 수치를 확인할 수 있다.

체결 가능한 보유기간을 직접 예측한 [연도별 순차 검증](annual_validation.ko.md)과 [주말 날짜 제외 검증](../results/walk_metrics_weekdays.csv)을 함께 제공한다. 각 연도 모델은 직전 연도 오차로 선택하며, 거래 없이 0을 예측하는 선택지도 포함한다. walk_predictions에는 신호일·진입일·손익 인식일과 각 학습 경계가 있다. walk_ledger에는 진입·반전·청산 비용이 들어 있다. 기존 실험과 새 실험은 목표와 평가 기간이 다르다.

2018~2026년 순차 검증에서 연도별 선택 전략은 기본 비용으로 3회 진입해 누적 −2.17%를 기록했다. 비용을 두 배로 높이면 진입이 0회였다. 기준모형 대비 MAE 개선의 95% 구간은 −0.33~+0.13bp로, 보유 구간 수익을 안정적으로 예측한다는 근거는 부족했다. 원본의 공급자와 계약 연결 방식을 확인할 수 없어 결과는 관측 가격을 이용한 모의 실험으로 해석한다.

## 실행

Windows PowerShell에서 이 폴더로 이동해 아래 명령을 실행한다. 검증 환경은 Python 3.11, CPU, 단일 Torch 스레드다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
.\.venv\Scripts\python.exe verify.py
.\.venv\Scripts\python.exe walkforward.py
.\.venv\Scripts\python.exe walkforward.py --weekdays-only
```

같은 Windows·Python 3.11 환경에서 간접 의존성까지 동일하게 설치하려면 위 설치 명령의 requirements.txt를 requirements-win311.lock으로 바꾼다.

기본 입력은 저장소 루트의 `data`다. 다른 위치에서는 두 명령에 `--data "데이터 폴더 경로"`를 붙인다. 결과는 이 폴더의 results에 저장한다. 검증 시점 이후 원자료가 변경되면 먼저 run.py를 다시 실행한다.

## 관측과 발표일

|입력|기존 처리에서 확인한 점|이번 실험|
|---|---|---|
|옥수수·대두 가격 엑셀|기존 코드는 WTI 날짜에 맞춰 병합하고 빈 가격을 직전 값으로 채웠다.|두 엑셀의 날짜 교집합에서 양수인 원본 가격만 사용한다. 두 파일에 행이 있는 날을 관측일로 정의한다. 같은 값이 반복되는 날도 원자료 기록을 따른다.|
|DSCI 가뭄 지수|MapDate는 관측 기준일이다. 기존 코드는 그 날짜에 값을 병합했다.|화요일 MapDate의 주별 지역 평균을 7일 뒤부터 사용한다. 통상 목요일 공개보다 늦게 사용하는 보수적 가정이다. 과거 예외 발표 시각 전부를 개별 대조한 것은 아니다.|
|작황·재고·에탄올·비료 및 금융 지표|작황 자료의 Week Ending은 주 종료일이고 재고·연료 자료는 연도·분기 기준이다. 기존 코드가 일부 날짜를 연·월 단위로 이동했지만 파일에는 실제 공표 시각과 당시 버전이 없다.|원 과제의 통합 CSV 수치는 exploratory에서만 비교한다. 마지막 행 이후에는 가장 최근 수치를 유지하므로 이 기간의 진단 결과는 지표 갱신 중단 영향도 포함한다.|

가뭄 지도의 자료 기준일과 통상 공개일은 [U.S. Drought Monitor 설명](https://droughtmonitor.unl.edu/About/WhatistheUSDM.aspx)을 참고했다.

## 예측 설계

- 종가를 관측한 날을 origin, 다음 공통 관측일을 date로 둔다. 예측표의 base, actual, pred는 각각 기준일 가격, 목표일 관측값, 예측값이다. Ratio는 대두 가격을 옥수수 가격으로 나눈 값이다.
- 기본 입력은 두 가격과 비율의 일별 로그 변화, 5일 이동평균 변화, 20일 변동성이다. published는 DSCI를 추가하고 exploratory는 공개 시점을 확인하기 어려운 지표도 추가한다. 모든 변형은 동일한 날짜를 사용한다.
- Persistence는 현재 가격을 다음 가격으로 예측한다. 나머지 모델은 다음 로그 변화율을 학습해 가격으로 환산한다. Ridge와 GRU에는 최근 12개 행, Gradient Boosting에는 최신 행의 요약변수를 사용한다. 기존 GRU의 24개 은닉 유닛·LayerNorm·Dropout 구조를 사용한다.
- 목표일 기준 2020년까지 학습, 2021~2022년 검증, 2023년부터 테스트다. 정규화는 학습 데이터에서 적합한다. 학습 중 GRU는 검증 MAE만으로 체크포인트를 결정한다. 주요 모델·입력 선택도 검증 MAE로 고정하며 사후 테스트 순위는 별도로 표시한다.
- MAE 개선율은 100 × (1 − 모델 MAE / 기준 MAE)다. 값이 양수면 같은 날짜의 기준보다 오차가 작다. 연도별 평가는 달력 연도 기준으로 마지막 연도는 부분 기간이다.

## 체결·회계 규칙

- 거래는 테스트 첫 종가 직전 자본 1, 포지션 0에서 시작한다. t 종가에 만든 신호는 다음 공통 관측일 종가에 체결한다. 이후부터 가격 변화에 따른 손익을 계산하고 마지막 종가에 모두 청산한다.
- 방향 전략은 예측 비율 변화의 절반을 동일 가중 스프레드의 예상 수익률 근사치로 사용한다. 그 크기가 왕복 비용을 넘어야 진입한다. 평균회귀는 t에 관측한 비율과 전날 생성한 t 예측 간 차이를 과거 60개 차이의 평균·표준편차로 표준화한다. ±1.5에서 반대 방향으로 진입하고 절댓값 0.5 미만에서 청산한다. SMA60은 과제에서 사용한 60일 평균 기준이다.
- 매 종가에 목표 비중을 대두 ±50%, 옥수수 ∓50%로 맞춘다. 거래비용은 가격 변화 후 보유액과 새 목표액 간 차액의 절댓값에 양쪽 각각 적용한다. 기본 편도 비용은 0.15%이며 비용 2배 시나리오는 진입 문턱도 올린다. 거래 횟수는 신규 진입·직접 반전의 합이다. 회전율은 초기부터 마지막 청산까지 일별 거래대금/직전 자본의 합이다.
- Sharpe는 무위험수익률 0, 연 252 관측일을 가정한다. 수익률 분산이 0이면 정의되지 않는다. 모의 손익은 실제 계약 체결이나 롤을 복원한 결과가 아니다.

## 검증

run.py는 모델별 날짜 집합, 원본 목표 가격 일치, 체결·반전 비용·청산을 확인한다. verify.py는 2025년 이후 가격과 입력값을 변형하고 전체 모델을 다시 학습해 이전 예측을 대조한다. 시계열 검증 범위는 이 변경 시나리오와 로컬 입력 파일에 한정된다.
